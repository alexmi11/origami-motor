These are files that go with the Macro Scale Electrostatic Origami Motor paper.

The data_analysis folder includes the compiled data and analysis scripts for motor speed, torque, mechanical parameters, and current.

The electrostatics_analysis folder contains a script which implements an electric field and torque analysis on the motor, solved with symbolic algebra.

The design_files folder contains scripts to be run with JSON-PCB (https://github.com/leomcelroy/json-pcb) to create the rotor and stator circuit boards, zipped Gerber PCB files, and STL CAD files for the rigid components.
